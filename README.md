# 常凯尧 · 个人作品页

静态个人作品页，主要展示地理信息、算法研发、AI 地图产品与研究经历。

- 页面：`index.html`，无构建步骤或第三方脚本。
- 样式：内联 CSS，兼容手机和桌面屏幕。
- `.nojekyll`：按普通静态文件发布。
- 目标地址：[changkio.github.io](https://changkio.github.io/)。

## 本地查看

可以直接用浏览器打开 `index.html`，或在目录中运行：

```bash
python -m http.server 8000
```

访问 `http://localhost:8000`。

## 内容维护

项目经历和学习演示分开展示。不包含私人电话、邮箱、未公开实验数据或商业算法实现。修改项目链接、研究状态和经历时，应以已确认的信息为准。

仓库文件本身不代表 GitHub Pages 已开启；需在 GitHub 仓库 Pages 设置中选择发布来源。
